# Day 3 - NumPy Array Operations

## Project

A Python program demonstrating fundamental NumPy array operations. This project focuses on accessing, modifying, and performing mathematical operations on arrays while exploring NumPy's powerful built-in functions.

## Features

- Access array elements using indexing
- Slice 1D and 2D arrays
- Modify array values
- Perform arithmetic operations on arrays
- Perform element-wise operations between arrays
- Use NumPy universal functions (ufuncs)
- Calculate array statistics
- Perform operations along rows and columns using axes
- Mini challenge using student marks dataset

## Concepts Practiced

- NumPy Arrays
- Array Indexing
- Array Slicing
- Array Modification
- Element-wise Operations
- Broadcasting
- Universal Functions (ufuncs)
- Aggregation Functions
- Axis Operations
- Array Statistics

## What I Learned

- NumPy allows element-wise arithmetic without using loops.
- Indexing and slicing work similarly to Python lists but also support multiple dimensions.
- Arrays can be modified directly by assigning new values.
- Universal functions simplify mathematical operations on entire arrays.
- Aggregation functions like `sum()`, `mean()`, `max()`, and `min()` provide quick statistical insights.
- Using the `axis` parameter allows operations to be performed row-wise or column-wise.
- Broadcasting makes it possible to apply operations to every element in an array efficiently.

# Day 5 - NumPy Splitting, Searching & Sorting

## Project

A Python program demonstrating NumPy operations for splitting, searching, and sorting arrays. The exercises use both one-dimensional and two-dimensional arrays to understand how NumPy works with structured data.

## Features

- Split 1D arrays into multiple parts
- Split 2D arrays along different axes
- Search arrays using conditions
- Find indexes of matching elements
- Sort 1D arrays
- Sort 2D arrays along different axes
- Practice conditional searching with real-world style marks data

## What I Learned

- `np.array_split()` divides an array into multiple smaller arrays.
- Arrays can be split along different axes.
- `np.where()` can be used to find the indexes where a condition is true.
- For a 2D array, `np.where()` returns row and column indexes separately.
- The indexes returned by `np.where()` can be used to access the matching values.
- `np.sort()` returns the sorted values of an array.
- The `axis` parameter determines the direction of operations on multidimensional arrays.
- NumPy makes it easier to search and manipulate large collections of numerical data.
- I practiced predicting NumPy outputs before running the code.

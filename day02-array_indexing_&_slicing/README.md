# Day 2 - NumPy Array Indexing and Slicing

## Project

A beginner-friendly exploration of NumPy array indexing and slicing. This project demonstrates how to access individual elements and extract portions of arrays from 1-D, 2-D, and 3-D NumPy arrays using different indexing and slicing techniques.

## Topics Covered

- Indexing 1-D arrays
- Negative indexing
- Indexing 2-D arrays
- Indexing 3-D arrays
- Basic array slicing
- Negative slicing
- Step slicing
- Reversing an array
- Slicing 2-D arrays

## Concepts Practiced

- NumPy Indexing
- NumPy Slicing
- Positive and Negative Indexing
- Multi-dimensional Arrays
- Row and Column Access
- Step Values
- Reverse Traversal

## What I Learned

- NumPy arrays use zero-based indexing.
- Negative indexing allows elements to be accessed from the end of an array.
- Multi-dimensional arrays require multiple indices to access specific elements.
- Slicing extracts a range of elements without modifying the original array.
- Step values make it possible to skip elements or reverse an array efficiently.
- Rows and columns of a matrix can be accessed easily using NumPy slicing syntax.

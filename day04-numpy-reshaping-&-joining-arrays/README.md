# Day 4 - NumPy Reshaping & Joining Arrays

## Project

A Python program demonstrating NumPy operations for reshaping, flattening, iterating, joining, and stacking arrays.

## Features

- Reshape 1D arrays into different dimensions
- Flatten multidimensional arrays
- Iterate through 1D and 2D arrays
- Concatenate arrays
- Join arrays along different axes
- Stack arrays vertically and horizontally
- Explore how array shapes change during operations

## Concepts Practiced

- `reshape()`
- `flatten()`
- `ravel()`
- Array Iteration
- `np.concatenate()`
- `axis`
- `np.stack()`
- `np.vstack()`
- `np.hstack()`
- Array Shapes

## What I Learned

- `reshape()` changes the structure of an array without changing the number of elements.
- The new dimensions must be compatible with the total number of elements.
- `flatten()` converts a multidimensional array into a 1D array.
- NumPy arrays can be iterated through using `for` loops.
- `np.concatenate()` joins arrays together and can use different axes for multidimensional arrays.
- `axis` determines the direction in which an operation is performed.
- `stack()`, `vstack()`, and `hstack()` provide different ways to combine arrays.
- Array shape is important when performing operations on multidimensional data.
- I practiced understanding NumPy errors by debugging incorrect function arguments.
